# Bang RL post-fix runtime and evaluation review

The current implementation addresses the prior report's silent-success and state-boundary failures. Default training now fails closed, application evaluation delegates to artifact-backed protocols, worker agent graphs are cloned and reseeded, and reward/action/ledger/PPO fixes are wired into the active paths. Evaluation resolves the requested opponent preset and closes each environment; direct diagnostic thresholds and JSONL reads are also corrected. **Watch for:** **confirmed MEDIUM** — owned evaluation loggers are never closed, and **confirmed MEDIUM performance** — public observation mapping still reserializes the complete event history. **Verdict**: NEEDS_CHANGES

## High-level view

Unsupported default training raises before reporting a job, while public evaluation requires an artifact and selects the primary or custom protocol instead of the old RandomAgent simulation. Compatibility checks, balanced primary seats, 500-game seeds, public-only model inputs, and non-mutating inference checks remain on this path.

`DummyVecEnv` now isolates mutable agent graphs; calculated rewards reach canonical data; domain actions normalize to Discrete(6); MainAgent elimination parks a real pending transition; and GAE segments by worker, episode, and rollout. Truncated transitions remain excluded from PPO.

Direct short environments reject unreachable diagnostic thresholds, immutable public event objects are shared, and `read_jsonl` reads once. **Confirmed** residuals remain: the public cache does not cache serialized mappings, and protocol-owned logger cleanup is incomplete.

### Artifact-backed application evaluation and protocol contract

The prior application evaluation defect is fixed (**confirmed**). `bang_rl/app/services.py:826-883` requires an artifact or artifact path and selects `PrimaryEvaluationProtocol` for `deterministic_v1` or `CustomEvaluationProtocol` otherwise. The old RandomAgent path is named `run_diagnostic`. `bang_rl/tests/test_application_services.py:test_public_evaluation_service_delegates_artifact_evaluation` verifies the adapter. The protocol keeps privileged roles/emotions in metric-only code and feeds model modules public observations; primary seed/seat rules and artifact fingerprint checks remain enforced.

### Worker agent isolation, canonical rewards, domain actions, and elimination lifecycle

These four defects are fixed (**confirmed**). `bang_rl/training/vec_env.py:215-242` deep-copies each agent graph and replaces its action RNG with a worker/agent-derived stream; `DummyVecEnv` applies this at `bang_rl/training/vec_env.py:567-575`. Episode-start callbacks reset the cloned emotion and role-belief state.

`bang_rl/data/collector.py:718-722` uses a configured reward breakdown total as the canonical acting reward while retaining the breakdown. `bang_rl/tests/test_episode_collector.py:test_calculated_reward_becomes_canonical_step_reward_and_truncation_has_no_terminal_reward` covers normal and truncated cases.

`bang_rl/training/ppo_trainer.py:56-111` decodes scalar and serialized domain actions, validates actor/target consistency, and rejects conflicts; `test_committed_domain_actions_normalize_to_discrete_six_and_reject_conflicts` covers PASS, BANG, and conflicts. `bang_rl/training/pending_transition.py:724-762` parks a MainAgent transition on elimination and defers terminal status/reward to environment completion; `test_main_agent_elimination_parks_real_transition_until_environment_termination` checks the absence of a fake PASS or next state.

### Segmented GAE and opponent preset resolution

The PPO and primary-evaluation fixes are complete (**confirmed**). `bang_rl/training/ppo_trainer.py:655-699` groups GAE by `(worker_id, episode_id, rollout_id)`, preventing advantage carryover across workers, episodes, or rollout cutoffs. `bang_rl/tests/test_ppo_trainer.py:test_segmented_gae_resets_between_workers_and_episodes` and `test_segmented_gae_rollout_cutoff_uses_only_its_transition_next_value` cover both boundaries.

`bang_rl/evaluation/protocol.py:338-345` resolves `evaluation.opponent_preset` from the configured map, and `PrimaryEvaluationProtocol.run` passes that preset to every game. `test_primary_resolves_requested_opponent_preset` verifies the selected ID/version. Primary validation still enforces the 500-game balanced deterministic contract; custom/stochastic runs remain separate.

### Evaluation environment closure and remaining logger lifecycle defect

Environment closure is fixed, but logger cleanup remains a **confirmed MEDIUM** defect. `bang_rl/evaluation/protocol.py:306-308` creates an internal `StructuredLogger` and records `_owns_logger`, yet neither protocol `run()` closes an owned logger. `CustomEvaluationProtocol.__init__` calls the superclass at line 801 and replaces the logger at line 802, orphaning the superclass-created handler. The `_run_game` finally block at `bang_rl/evaluation/protocol.py:477-488` closes tracked environments only; it does not close factory-created application loggers or protocol-owned loggers.

Caller-supplied loggers should remain caller-owned, but internally created protocol loggers and explicitly application-owned factory handlers need a close path. `test_each_evaluation_game_closes_environment_on_normal_truncated_and_exception` checks only environment closure. Add counting-logger tests for normal, truncated, and exception paths, plus a factory ownership test.

### Direct diagnostics validation and incomplete public observation caching

Direct short-environment diagnostics are fixed (**confirmed**). `BangEnvironment` now constructs `LongGameDiagnostics` with supplied thresholds, so unreachable defaults raise through shared validation. `bang_rl/tests/test_long_game_diagnostics.py:test_direct_constructor_rejects_unreachable_default_thresholds` and `test_direct_constructor_valid_short_thresholds_emit_each_crossing_once` cover rejection and one-time crossings. The dedicated diagnostics channel retains privileged state while public records remain role-redacted.

The public-history issue is only partially fixed and remains a **confirmed MEDIUM performance** defect. `EnvironmentState` carries `_public_event_log` through immutable transitions (`bang_rl/env/types.py:710-755`), and `to_public()` shares it (`bang_rl/env/types.py:819-860`), removing the original filter scan from each `to_public()` call. But `PublicEnvironmentState.to_observation_dict()` still calls `event.to_public_dict()` over the complete history twice (`bang_rl/env/types.py:600-624`). `__getitem__` and `keys()` each call `to_observation_dict()` again (`bang_rl/env/types.py:630-635`), while primary evaluation builds `values = {key: observation[key] for key in observation.keys()}` at `bang_rl/evaluation/protocol.py:381`. One MainAgent boundary can therefore reserialize the full history repeatedly. `EnvironmentState.__post_init__` also recomputes the derived public tuple to validate the cache at `bang_rl/env/types.py:746-755`, retaining cumulative history-scan cost during transitions.

`bang_rl/tests/test_observation.py:test_public_event_projection_is_shared_but_observation_containers_are_detached` checks structural sharing and detachment, but not serialization call counts or long-history complexity. Cache serialized public event fields or one observation mapping per immutable state, preserve detached mutable return values, and add a call-count/benchmark regression test. The existing cache filters to public events, so this residual is performance-only rather than a privacy leak.
